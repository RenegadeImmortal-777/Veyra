# Veyra Horizon Roadmap

## Current platform
- Complete Veyra 1 compatibility interpreter
- Native Rust bytecode VM
- Unified CLI
- Project manifests and builds
- Formatter and checker
- Test runner
- Standard-library seed modules
- VS Code syntax support and snippets
- Windows user installation

## Native parity targets
Functions and closures, modules, maps, for loops, static typing, generics, structured errors, bytecode serialization, optimizer, debugger hooks, garbage collector, async runtime, package registry, language server, cross compilation, WASM backend, native code generation, reproducible builds, sandboxing, signed packages, compiler bootstrapping, and self-hosting.

## Long-horizon research
Capability security, deterministic distributed execution, formal verification, proof-carrying packages, heterogeneous CPU/GPU compilation, verified optimizer passes, persistent program state, autonomous refactoring, and backwards-compatible language evolution.
